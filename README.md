# CodeAlpha Basic Chatbot 🤖

#  About the Project:

A simple rule-based chatbot built using Python. It interacts with users through the terminal and responds to predefined messages.

# Features:

- Greets users with hello or hi.
- Responds to "How are you?"
- Introduces itself when asked its name.
- Exits the conversation when the user types "bye".
- Handles unknown messages with a default response.

# Technologies Used:

- Python
- Functions
- If-elif-else statements
- While loop
- User input and output
- String methods

# How to Run:

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

python chatbot.py

Project Type:

Console-based Python application.
